# SUBSYSTEM：STM32F407 触摸事件桥 + 墨水屏（rt_stm32）

## 控制职责
负责 2.0TP 触摸屏输入：I²C3 轮询 CST816D，识别手势后经 I²C1 主机向 ECW6700
（从机 0x42）写 1 字节命令（`0x01` 触摸、`0x11`–`0x14` 手势）。不参与录音、存储、网络。
另外开机驱动 800×480 墨水屏（SSD1677 系，SPI3 共享总线、9-bit 字）全刷显示一次 LOGO。

## 对外接口
- **板间 I²C（I2C1 主机，PB8/PB9）**：写 1 字节命令。
  - `0x01` TOUCH：仅录音/上传（长按、横向滑动、未知手势）。
  - `0x02` PING：上电心跳（预留）。
  - `0x11`/`0x13`：单击/上滑 → 录音/上传 + 正面音效。
  - `0x12`/`0x14`：双击/下滑 → 录音/上传 + 负面音效。
- **触摸（I2C3 控制器，PA8/PC9，RESET=PD15）**：CST816D，寄存器 0x01 读 6 字节
  （GestureID + 手指数 + 坐标）。
- **墨水屏（EPD 接口，SPI3 共享总线）**：SSD1677 系 800×480 1bit，9-bit 字（D/C 固定低）。
  SCK=PC10 / MOSI=PC12（与 LCD 共用）、CS=PA15、RES=PA13、BUSY=PD8、D/C=PC3（固定低）。
  开机全刷一次 48000 字节 LOGO（`epd_logo_bits`，Bayer 抖动）；BUSY 超时不阻塞主循环。
  SD 取图路径已实现但默认关闭（ECW 从机长块 TX 会拉死 I2C 总线）。
- **调试串口（USART3，PB10/PB11，115200）**：启动、手势、链路统计日志。

## 边界
- 不实现 I²C 从机、不实现变长帧/应答/重传协议；
- 不接触 SD 卡、音频；墨水屏只在开机显示一次 LOGO，不做动态刷新/文字排版；
- 手势识别优先用 CST816 硬件 GestureID，软件兜底单击/双击/上下滑；
  单击延迟 300 ms 以区分双击。
