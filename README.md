# 黑壳松 · 美好时刻陪伴宠物

桌面 AI 宠物：持续监听环境声音，触摸屏按下「捕捉此刻」后，把最近 N 分钟的录音（默认 300 秒，可配）传到手机，
经语音识别 + 大模型生成一张带时间、地点、文字的「记忆卡片」，存进手机的时间线里。

硬件：STM32F407（音频 / 存储 / 屏 / 交互）+ ECW6700（Wi-Fi / BLE / TTS），两块板用 I2C 做控制通道，
音频批量数据走 UART（见下方「关于总线」）。

## 架构

```
        ┌──────────────────────── 手机 App（PWA / 本地网页） ────────────────────────┐
        │  Wi-Fi：HTTP Range 拉取音频        BLE：GATT 分包（安卓 Chrome）            │
        │  解码 ADPCM → WAV → ASR → LLM → 卡片渲染 / 分享 / 时间线                     │
        └───────────────▲───────────────────────────────────────▲──────────────────┘
                        │ 设备 SoftAP 或 家里 Wi-Fi              │
        ┌───────────────┴───────────────────────────────────────┴──────────────────┐
        │ ECW6700：Wi-Fi/BLE 桥、HTTP 服务、TTS（UART 接语音合成模块）              │
        └───────────────▲───────────────────────────────────────┬──────────────────┘
                        │ I2C 控制 / 事件                        │ UART 音频批量（≤1MB/s）
        ┌───────────────┴───────────────────────────────────────▼──────────────────┐
        │ STM32F407：ADC 采音 → ADPCM 编码 → SD 环形缓存 → 捕捉拷贝 → UI/触摸      │
        │           2.0" TFT + 触摸、4.2" 墨水屏、按键、LED                          │
        └──────────────────────────────────────────────────────────────────────────┘
```

## 快速开始

1. **接线**：按 `docs/01-wiring.md` 的表接。麦克风、SD、TFT、EPD、ECW6700 的 I2C/UART 都要接。
2. **烧固件**：按 `docs/04-build-flash.md`，STM32CubeIDE 或 `make` + ST-Link 均可。
3. **开 App**：`python3 -m http.server 8000 -d app`，手机浏览器打开 `http://<电脑IP>:8000`。
   没接硬件时先跑 `python3 tools/mock_device.py`（跑在 8001），App 里把设备地址填 `http://<电脑IP>:8001` 就有一个完整可点的假设备。

## 两个必须先知道的前提

1. **I2C 不能用来传音频。** 400 kHz 的 I2C 实际有效约 25–30 kB/s，300 秒 ADPCM 音频约 1.45 MB，要传 50 秒；
   600 秒要传近 2 分钟。所以 I2C 只做控制/事件，**音频必须另加一对 UART 线**（`PB10/PB11`，2 Mbaud，约 200 kB/s）。
   杜邦线加两根即可，固件已经两种都实现了，改一个宏就切换。
2. **ECW6700 的固件要按它的 SDK 补。** 我这边没有它的 SDK，所以桥接层给的是「可移植核心 + 端口钩子」：
   协议解析、分包、缓冲、HTTP Range 全部写好了，你只要把 4 个钩子（BLE 收、BLE 发、socket 收、socket 发）接上它的 API。
